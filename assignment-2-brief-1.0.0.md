# Assignment 2 Brief: AI Study Coach

## What is this

A course assignment for the Oxford AI Engineering programme.
The task is to build a small "AI Study Coach" as a single Python script that demonstrates five areas of Python competency taught across the course modules.

## Why it exists

This is not a product. It is a demonstration of skills.
The assessors want to see that you can wire together Python fundamentals, OOP, data handling, machine learning, and LLM integration into one coherent program.

The grading is binary: Complete or Not Complete. Every required capability must be present and functional. There is one submission attempt.

## What the program should do (from the user's perspective)

A student runs the script in a terminal. The program:

1. Asks them about themselves and their recent study habits.
2. Shows them a summary of their study data with charts.
3. Predicts whether they're at risk of falling behind, using a trained classifier.
4. Lets them ask a "Coach Chat" questions about studying, with answers grounded in a small knowledge base.

The whole thing runs sequentially in a single terminal session. No web UI, no database, no deployment.

## Who the audience is

The course assessors. They will run the script, check that all required sections work, and verify the deliverables match the brief.

## What success looks like

The zip file is submitted on time. The script runs without errors. Every section specified in the assignment PDF is present and demonstrably functional. The docstring at the top explains how to run it.
